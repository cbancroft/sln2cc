1. INTRODUCTION                                         *msvclsp-introduction*

msvclsp.nvim parses a Visual Studio solution, generates a compile_commands.json
compilation database from it, and starts clangd against that database — giving
C/C++ language support in Neovim for projects built with MSBuild rather than
CMake.
